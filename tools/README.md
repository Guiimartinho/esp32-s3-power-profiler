# Tools

Scripts used to build and check the instrument, as opposed to the host
software its users run.

Status: not started.

| --- | --- |
| `calibration/` | Gain, offset and DAC calibration against reference equipment, as defined in section 8 of the [specification](../docs/specification.md) |
| `production-test/` | Checks run on every assembled board |
